
# Ultrasound – Project Archived
## ❗ No Longer Maintained

This project is no longer maintained. Its original purpose detecting and extracting text box lines for a separate audio-playing application, is now obsolete.

### ✅ Why?
Thanks to the **[FFNx driver](https://github.com/julianxhokaxhiu/FFNx)**, this functionality is fully integrated into the game engine, rendering Ultrasound unnecessary

### 🔗 What to Use Instead
Please use the latest version of **[7th Heaven](https://github.com/tsunamods-codes/7th-Heaven)**, which comes with FFNx built in.

---

## 📦 Repository Status
This repository is now in **archive mode** and will not receive further updates or support.
